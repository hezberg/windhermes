# Serenity 行业分析 Skill

## 中文名称

Senerity 行业分析 Skill

## 能力定位

用于行业深度研究。先形成行业结构和稀缺层级判断，再映射公司，不急于给股票排序。

## 工具调用

1. `wind_financial_reference_content`：提取行业逻辑、产业链框架、历史研究和公司覆盖。
2. `document_search`：查询研报、公告、新闻、政策、路演和法规。
3. `get_wind_data`：查询行业相关上市公司财务、估值、行情、筛选指标。
4. `wind_web_search`：补充招投标、官网、地方项目、协会、标准和行业资料。
5. `quote_get_sector_realtime_performance`：判断板块热度和近期市场定价。

## 执行流程

1. 明确行业边界和市场范围。
2. 判断系统变化：需求为什么变化，旧系统哪里被拉紧。
3. 拆分产业链层级：下游、系统、模块、核心部件、设备、材料、测试、基础设施。
4. 找稀缺层：低供应商数量、长认证周期、扩产困难、材料纯度、客户认证、产能预约等。
5. 梳理竞争格局：龙头、追赶者、替代路线、跨市场公司。
6. 映射上市公司，但不直接把热度最高的公司放前面。
7. 评价证据强弱和缺失证明。
8. 给出后续验证指标。

## 输出格式

```text
核心结论：
[行业真正紧的是哪几层]

1. 系统变化
2. 产业链地图
3. 稀缺层级排序
4. 竞争格局
5. 相关上市公司映射
6. 证据强弱
7. 热门但需要降级的方向
8. 什么情况说明判断错了
9. 下一步验证路径
```

## 质检清单

- 不把行业分析写成泛泛研报。
- 必须指出“哪个环节更难扩”。
- 必须区分行业逻辑、公司映射和股票排序。
- 对当前事实必须调用工具或标注待验证。
- 不输出交易指令。

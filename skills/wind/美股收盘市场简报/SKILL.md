# 美股收盘市场简报

## 何时使用

- 用户要求生成“美股收盘市场简报”“隔夜美股综述”“美股复盘”。
- 盘前需要了解隔夜海外市场表现及其对 A 股的影响。
- 按每日早间 cron 任务自动生成。

## 执行流程

1. 使用 `wind_financial_reference_content` 查询最新的“全球股市概况与美股收盘综述”。
2. 从结果中提炼三类信息：

   - **指数与个股表现**：道指、标普500、纳指涨跌幅与收盘点位；美股科技七巨头及重点公司走势；欧洲、亚太市场整体表现。
   - **核心主线与概念资讯**：市场主导逻辑、2–3 个最重要板块或概念，以及对应的重要资讯与新闻信息。
   - **宏观与全球局势**：美联储、降息预期、通胀、利率、美元、美债、黄金、原油、地缘局势及全球风险偏好变化。

3. 生成三段日报，采用“结果 + 原因 + 影响”的写法，避免研究报告口吻。

## 输出要求

- 语言简洁，保证数据的准确性。
- 按照标题、内文的形式分段。
- 去重，不重复罗列相近信息。
- 概念资讯控制在 2–3 个，格式为：`概念名称：重要资讯与新闻信息`。

## 输出样式

```markdown
## 重要指数与个股表现
（约 200 字）

## 核心主线与概念资讯
概念名称：重要资讯与新闻信息
...
（约 300 字）

## 宏观资讯与全球新闻
（约 200 字）
```

## 调度建议

建议按北京时间周一至周五 07:00 自动运行（cron：`0 7 * * 1-5`）。

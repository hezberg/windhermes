## 技能定位

本技能模拟专业研究团队的协同工作方式：围绕用户输入的市场主题，先识别核心研究问题，再动态拆分为多个独立研究维度，每个维度形成独立子报告，最后提炼为综合终版报告。

**核心原则**：研究不能只复述价格涨跌，必须回答——发生了什么、为什么发生、当前方向是什么、有哪些支持证据、有哪些反方证据、哪些后续信号可以验证或推翻判断。

## 执行总览

```
Step 1: 验证输入 → 主题是否明确？关注资产是否可解析？
Step 2: 加载执行规范 → 确认 shared/execution-constraints.md 和 shared/writing-standards.md 已加载

Step 5: 生成研究计划 → 输出研究计划文件
Step 6: 并行数据获取 → 所有维度同时发起 get_wind_data 或 document_search / wind_financial_reference_content 查询
Step 7: 数据验证与 fallback → 检查数据完整性，执行降级策略
Step 8: 逐维度撰写子报告 → 每个维度独立成文

Step 12: 输出全部文件 → 写入 /project/ 目录
```

## 研究维度动态拆分规则

### 拆分原则

每次执行时，根据主题特征从以下维度池中**动态选取**4-8个最相关的维度。**严禁机械套用固定模板**，每次拆分应随主题变化。

### 维度池

| 维度类别 | 可选方向 | 适用场景 |
|---------|---------|---------|
| 宏观环境 | 全球流动性、利率周期、汇率、地缘政治、贸易政策 | 涉及跨市场传导、大宗商品、出口导向行业 |
| 市场风格 | 成长vs价值、大盘vs小盘、动量vs反转、风险偏好 | 涉及市场整体方向判断 |
| 产业链 | 上游成本、中游制造、下游需求、库存周期、产能利用率 | 涉及具体行业或赛道 |
| 公司财务 | 营收结构、利润率趋势、现金流质量、资本开支、ROE拆解 | 涉及具体公司或行业盈利判断 |
| 估值 | 历史分位、跨市场比价、盈利预期修正、PEG | 涉及投资时机判断 |
| 资金结构 | 主力/散户行为、北向/南向资金、ETF资金流、融资融券 | 涉及市场情绪和资金面 |
| 技术路线 | 技术迭代、替代风险、标准之争、研发投入对比 | 涉及科技/新兴产业 |
| 跨市场传导 | A-H溢价、美股映射、汇率传导、全球供应链联动 | 涉及多市场 |
| 政策与监管 | 产业政策、反垄断、环保、数据安全、补贴退坡 | 涉及政策敏感行业 |
| 风险因素 | 尾部风险、集中度风险、流动性风险、地缘风险 | 所有主题均应涉及 |
| 机构观点 | 券商一致预期、评级变化、目标价调整、多空分歧 | 所有主题均应涉及 |

### 拆分流程

1. 从主题中提取3-5个关键词（行业、资产类别、驱动因素、地理范围）
2. 根据关键词匹配维度池中最相关的方向
3. 每个选定维度必须对应一个**可证伪的子判断**（而非信息分类标签）
4. 确保维度之间相互独立，避免语义重叠
5. 至少包含一个风险维度

## 成果一：研究计划

### 内容要求

研究计划文件须包含：

1. **核心研究问题**：将主题转化为一个可证伪的核心判断句
2. **研究维度清单**：4-8个维度，每个维度说明：
   - 对应的子判断
   - 该维度的重要性（为什么对回答核心问题不可或缺）
   - 所需数据和资料类型
   - 重点验证的假设
3. **关键不确定性**：列出当前已知的最大信息缺口
4. **研究边界**：明确本次研究不覆盖的范围

### 数据获取

研究计划本身不需要外部数据，基于Agent对主题的分析直接生成。

## 成果二：独立子报告（4-8份）

### 每份子报告结构

每份子报告必须包含以下全部要素：

1. **研究问题**：该维度对应的子判断
2. **直接结论**：开门见山，1-2句话
3. **核心数据**：支撑结论的关键数字，标注来源和时点
4. **产业或市场传导链**：从驱动因素到市场表现的因果链条
5. **支持证据**：来自数据的正面证据
6. **反方证据**：与结论矛盾或需要警惕的信号
7. **机构观点**：券商/研究机构的相关判断
8. **尚未解决的问题**：当前数据无法回答的关键疑问
9. **后续验证信号**：未来可验证或推翻本子报告判断的具体指标或事件
10. **数据时间和资料来源**：明确标注每条数据的截止时间和来源类型

### 数据获取

每个子报告的数据获取分为两层：

**第一层：确定性查询**（每个子报告必须执行）

```yaml
# 结构化数据查询
query_structured:
  tool: get_wind_data
  type: dataquery
  question: "[维度相关指标]截至最新交易日/最新报告期的数据"
  purpose: 获取核心定量证据

# 非结构化信息查询
query_unstructured:
  tool: document_search
  type: rag
  question: "[维度相关的完整自然语言问句]"
  purpose: 获取研报观点、公告信息、行业分析
  freshness: "[当前日期前推3个月]-[当前日期]"
```

**第二层：动态查询生成**

根据维度特征，执行时LLM自主推导额外查询：
- 识别该维度的2-3个核心追踪指标
- 按 dataquery 黄金准则构造查询语句
- 约束：禁止无时间范围查询；单条查询指标不超过6个

### 写作要求

- 观点先行，证据跟随
- 数据融入叙述，非bullet堆砌
- 区分"数据显示"（事实）、"我们认为"（判断）、"预计"（预测）
- 对证据不足的判断降低确信度或删除
- 保留反方证据和替代解释

## 成果三：综合终版报告

### 核心要求

综合终版报告必须**重新提炼和编辑**，不得简单拼接子报告。应站在更高层次整合各维度发现，形成统一叙事。

### 必须包含的九大模块

#### 1. 核心判断（3-5项）

每项判断格式：`[判断结论]` + `[置信度：高/中/低]` + `[关键支撑证据]`

#### 2. 当前最重要的市场主线

用1-2段叙述当前市场围绕该主题的核心矛盾是什么，各方力量如何博弈。

#### 3. A股、港股、美股传导差异

- 同一主题在三地市场的传导机制差异
- 定价效率、投资者结构、政策环境导致的反应差异
- 跨市场套利或对冲含义

#### 4. 行业盈利弹性、估值约束与持续性

- 不同行业对主题的敏感度排序
- 当前估值是否已反映预期
- 盈利改善的可持续性判断

#### 5. 未来1-2周重要催化和风险

- 具体事件日历（财报、数据发布、政策节点）
- 可能引发剧烈波动的情景
- 短期交易层面的注意事项

#### 6. 未来1-2个季度盈利及产业验证

- 即将到来的财报季中需要重点验证的假设
- 产业链上下游的订单、价格、产能信号
- 盈利预期修正的可能方向

#### 7. 中长期产业趋势

- 3年以上的结构性变化方向
- 技术、人口、政策等慢变量的影响
- 当前主题在长周期中的位置

#### 8. 用户关注资产动态映射

- 从关注清单中筛选与当期主线相关的资产
- 对相关资产进行当前主营业务、最新财报、近期催化的快速核查
- 资产相关性较弱时保持沉默，不强行关联

#### 9. 可能推翻本报告判断的信号

- 列出3-5个具体、可观测的反转信号
- 每个信号说明：观测什么指标、什么阈值意味着判断需要修正
- 区分"短期噪音"和"趋势反转"

### 数据获取

综合终版报告以子报告数据为基础，额外查询：

```yaml
# 跨市场估值对比
query_cross_market:
  tool: get_wind_data
  type: dataquery
  question: "[相关行业/指数]在A股、港股、美股的最新估值指标对比"
  purpose: 跨市场传导差异分析

# 近期事件日历
query_events:
  tool: document_search
  type: rag
  question: "[相关公司/行业]未来两周的重要事件和催化剂"
  freshness: "[当前日期]-[当前日期+14天]"
  purpose: 短期催化与风险识别
```

## 成果五：用户关注资产映射表

### 处理流程

1. 读取用户关注资产清单（用户输入优先，否则使用 `references/default-watchlist.md`）
2. 对每个资产核查：当前主营业务、最新财报关键数据、近期公告、估值水平
3. 判断与当期研究主题的相关性（高/中/低/无关）
4. 仅将相关性"高"和"中"的资产纳入映射表

### 映射表格式

| 资产 | 相关性 | 核心关联逻辑 | 关键数据 | 风险提示 |
|------|--------|------------|---------|---------|
| ... | 高/中 | 一句话说明 | 最新关键指标 | 主要风险 |

### 数据获取

```yaml
# 批量获取关注资产基本面
query_watchlist:
  tool: get_wind_data
  type: dataquery
  question: "[关注资产列表]截至最新报告期的营收、净利润、ROE、PE(TTM)、PB、近1个月涨跌幅"
  purpose: 关注资产基本面快照

# 近期公告与催化
query_watchlist_news:
  tool: document_search
  type: rag
  question: "[关注资产列表中相关性高的公司]近期重要公告和新闻"
  freshness: "[当前日期前推1个月]-[当前日期]"
  purpose: 识别近期公司级催化
```

## 成果六：研究质量摘要

### 内容

1. **数据完整性评估**：哪些维度数据充分，哪些存在缺口
2. **信息源分布**：结构化数据 / 公司公告 / 券商研报 / 媒体报道 / Agent推断 各占比例
3. **关键信息缺口**：对判断影响最大的数据缺失
4. **替代解释的合理性**：反方证据的强度评估
5. **时效性评估**：所用数据的截止时间，是否存在滞后风险
6. **后续建议**：建议用户在何时、基于什么信号重新审视本报告

## 事实与质量标准

### 必须做到

- 标注数据截止时间和资料发布时间
- 区分历史数据、预测数据和模型推断
- 区分公司正式披露与券商观点
- 对相互冲突的数字说明不同口径
- 对证据不足的判断降低确信度或删除
- 保留反方证据和替代解释
- 避免重复、模板化和过度免责声明

### 严格禁止

- 把券商预测写成公司事实
- 把媒体传闻写成正式公告
- 把单日涨跌写成中期趋势
- 把成交额或大单指标直接写成机构资金流
- 混用盘中与收盘、财年与自然年、不同币种或不同会计口径
- 在找不到公司催化时编造完整故事
- 输出账户仓位、买卖数量、止损位或自动交易指令
